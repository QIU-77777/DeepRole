# 空间化叙事垂直切片开发 spec

状态：已确认，开发中

## 目标

把 DeepRole 的《未名剧社》从聊天入口扩展为 3/4 俯视的空间化叙事游戏。首个交付物是可内部完整试玩的垂直切片，不替换旧聊天客户端，也不要求公开发行品质。

## 已确认范围

- 桌面 Web、本地单用户、简体中文、单人游戏。
- Vue 3 + TypeScript + Phaser 3 + Vite；FastAPI 继续负责 AI、记忆、存档和语义世界状态。
- `32×32` Tile 的固定镜头 3/4 俯视 2D；八方向移动与八方向动画。
- 四张互联灰盒地图：校园中心、艺术楼走廊、剧社活动室、天台。
- Tiled JSON 是正式地图的权威来源；灰盒阶段使用同构的地图数据。
- 键盘移动、单一上下文交互键、小地图、局部对话面板和底部旁白条。
- 首版无物品、手机、多人、战斗、经营、动态 NPC 生成或 NPC-NPC AI 对话。
- 主要角色使用完整 Agent；环境 NPC 只使用预写气泡和基础日程。
- 首版故事保留林溪、沈知意和《未名剧社》的既有记忆系统。

## 时间模型

`story_time` 是唯一权威时间，内部保存季节、周次、星期和分钟；现实时间只作为存档元数据。走路、菜单、模型等待和离线不推进时间；地图切换、完整对话、休息和日结按行为时长表推进。日结通过校园中心的“返回宿舍”出口完成。世界线读取会完整恢复叙事时间、天气、NPC 日程和事件状态。

当前垂直切片恢复“秋季第 1 周、周三傍晚、距离公演约六周”的世界设定，但只实现最初数日和三个关系节点。

## 空间状态边界

- Phaser 负责逐帧移动、碰撞、镜头和动画。
- FastAPI 负责地图 ID、语义 waypoint、出口转换、同行、事件和叙事时间。
- 普通坐标只做节流快照，不能直接触发剧情。
- NPC 位置必须通过受校验的语义移动工具改变；玩家不能被文本传送。
- 普通地图切换不调用 AI；真实剧情事件才经过 narrator。

## 对话与可见性

- 玩家靠近 NPC 后按 `E` 开启交谈；参与双方锁定移动。
- 主动对象必须优先回应；同场最多再有一名角色插话。
- 同一场景的主要角色默认听见公开发言；私语由 UI 显式指定目标。
- 听众按每轮发言重新计算；沉默听众仍可形成独立记忆。
- narrator 后台先路由并开启新 turn；该轮的玩家输入、旁白、回应和工具结果共用 `turn_no` 与 `interaction_id`。
- narrator 可选 `display_text`：对话中显示在局部面板顶部，探索中显示为底部旁白条。

## 关系、记忆与存档

保留 Soul、Status、EpisodeMemory、Understanding 四层认知模型，新增 `relationship_state.json` 作为当前关系状态而非第五层记忆。关系使用阶段、标签和自然语言描述，不使用隐藏好感数值。人物档案展示完整 NPC 私有记忆图。

运行状态持续落盘以支持刷新恢复，但只有玩家手动保存才创建不可变世界线节点。创建节点前等待关键关系、事件、历史和记忆写入完成；读取旧节点前提示保存当前未命名状态。旧聊天存档尽力迁移关系、记忆和历史，重新建立空间状态。

## 里程碑

1. 新客户端骨架、灰盒地图、移动和本地交互。
2. 空间状态 API、出口、碰撞、小地图和运行态恢复。
3. NPC 结构化日程、寻路、离屏状态和同行。
4. 局部对话面板、公开／私语、SSE 和 narrator 后台化。
5. 事件规则、工具白名单、关系状态和沉默听众记忆。
6. 人物档案、记忆图、线索、历史、手动世界线和迁移。
7. 自动化闭环、调试面板、性能、音频和正式资产替换。

## 当前实现边界

已实现里程碑 1–2 的可运行基础，并接通里程碑 3/4/5/6/7 的首版闭环：独立 Vue/Phaser 客户端、四张灰盒地图、八方向移动/朝向动画、碰撞、镜头、出口切换、上下文交互提示、最小 HUD、按故事时间投影的基础 NPC 日程、区域出口图语义寻路路线、四张 Tiled JSON 地图源与对象层归一化、碰撞矩形上的八方向逐格 NPC 路径动画、天气/昼夜阶段、受白名单约束的语义 NPC 移动工具及其地图可见性同步、完整对话推进 5 分钟、宿舍出口日结、公开/私语听众选择、沉默听众记忆吸收、`display_text` 旁白、空间对话取消与失败重试、`interaction_id` 与工具结果历史、确定性空间事件、局部对话面板到现有 SSE `/api/chat` 的空间上下文接线、人物档案私有记忆图，以及可解释的 `relationship_state.json`。空间模式会限制听众、保证主要对象优先回应，并避免 narrator 写回地图位置。旧聊天页面仍保持不变。

尚未实现：正式美术资产与音频、可由剧情启停的同行队列，以及更大地图上的性能优化。当前构建和本地 `/game` smoke test 已通过。
