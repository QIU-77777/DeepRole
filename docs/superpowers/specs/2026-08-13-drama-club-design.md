# 大学话剧社剧本（drama）设计文档

日期：2026-08-13
状态：已批准（设计阶段）

## 1. 目标与范围

为 DeepRole 新增一个非职场、青春友谊向的故事模板，替换原 `modern` 的职场恋爱设定。
核心变化：去除职场权力关系与恋爱擦边，改为大学话剧社里大一新生与两位大二学姐因筹备校庆公演而结成的友情。

**包含**：世界观、三位角色（玩家 + 两位学姐）、开场、文件结构、与 DeepRole 机制的对接点。
**不包含（YAGNI）**：恋爱主线、职场流程、复杂支线剧本、额外 NPC 角色（首版仅两位学姐 + 玩家）。

## 2. 世界观与前提

- 某大学「未名剧社」，秋季学期。
- 距离校庆公演还有 **6 周**，剧社正在排一部原创轻喜剧《晚风来信》（关于错过与重逢）。
- 公演成败关系剧社下年度的经费与场地，是全员共同目标。
- 核心张力：两个性格迥异的学姐 + 一个新人 + 一台戏，在排练磨合中从陌生到能互相兜底的朋友。

## 3. 角色

### 玩家 — 叶清让（大一新生，三字）
刚加入剧社，被分配跟两位学姐筹备公演。一开始啥都不会，从头学灯光/道具/走位，是剧组的「新人温度计」——他的慌乱与成长映出整个组的气氛。

### 学姐 A — 林溪（大二，台前型 / 主演，二字）
外放、自来熟、把新人当自己人。排练时她在台上带气氛，台下总顺手把最累的活揽一半。喜欢用玩笑化解尴尬，被认真夸时会耳朵红一下。

### 学姐 B — 沈知意（大二，幕后型 / 编剧统筹，三字）
冷静、观察细、话不多。不抢镜，但谁状态不对她第一个察觉，然后用最不动声色的方式兜底（比如默默把你的台词卡写好递过来）。

两位均为大二、同届，无权力差；一个台前一个幕后，天然互补。

## 4. 开场场景

**某大学 · 未名剧社活动室 · 周三 18:30（秋季学期，校庆公演倒计时 6 周）**

叶清让（你，大一新生）第一次推开剧社活动室的门，满墙剧本和灯架。穿卫衣的女生从梯子上探出身，把一张道具清单拍你手里："林溪，大二，这次公演我演女主——你就是新来的道具组吧？欢迎。"她笑得近，顺手把最沉的那箱往自己这边拉了一半。

角落里另一个女生头也没抬，把一张写好的台词卡推到你面前，上面连你的走位都标好了。"沈知意，编剧。你那段独白周四前要背完。"说完又低头改她的本子，笔尖却在你名字上顿了一下。

林溪凑过来压低声音："别怕她，她就是这样的——但她说'要背完'的时候，是真的会盯着你。"

## 5. 文件结构与对接

新建 `data/templates/drama/`，角色目录用拼音 id（对齐 `modern` 的 chenxiao/guyining 约定）：

```
drama/
├── opening.txt              # 第 4 节开场文本
├── opening_choices.txt      # 开局可选行动（2-3 条玩家口吻）
├── narrator/
│   ├── soul.md             # 旁白：剧社导演视角，友谊向，公演驱动
│   ├── status.md           # 当前时间 / 场景 / 角色位置 / 叙事焦点
│   ├── tasks.md            # 剧情种子（可选）
│   └── pending_events.json # 待触发事件队列（空或初始几条）
├── linxi/                  # 林溪
│   ├── soul.md             # 六段：identity/goal/past/habits/reactions/voice
│   ├── status.md           # 心境 / 和玩家的关系 / 对沈知意的看法 / 在意的事
│   ├── intents.json        # 打算队列
│   └── memory_draft.jsonl  # 空草稿（或初始 1 条）
└── shenzhiyi/              # 沈知意
    ├── soul.md
    ├── status.md
    ├── intents.json
    └── memory_draft.jsonl
```

玩家 `叶清让` 不入角色目录（与 `modern` 的玩家处理一致，玩家身份在 narrator soul / opening 中定义）。

### 注册为新可选模板
- 前端模板选择列表需加入 `drama`（标题如「未名剧社 · 晚风来信」）。
- 若 `config.toml` 或 `repository/config.py` 有显式 story_id 白名单，需把 `drama` 加进去。
- 其余机制（narrator 路由、visible_to、memory/understanding、consolidation、存档）全部复用，无需改动代码。

## 6. soul.md 格式约定（对齐 modern）

每个角色 soul.md 含六段标签：
```
<role>林溪</role>
<identity>...</identity>
<goal>...</goal>
<past>...</past>
<habits>...</habits>
<reactions>...</reactions>
<voice>...</voice>
```
`goal` 写深层愿望（能力/成就 + 关系渴望），但此处关系渴望为「被当作能托付的伙伴」而非恋爱。

## 7. 成功标准

- 选 `drama` 模板可正常开局，开场文本与两位学姐出场符合设计。
- 玩家与林溪/沈知意的互动能逐步沉淀为 EpisodeMemory / Understanding（沿用现有管线）。
- 公演倒计时作为叙事焦点，可由 state_updater 从两位学姐的「打算」同步出待触发事件（如「第一次联排」「服装到位」「公演夜」）。
- 全程无职场权力关系、无恋爱擦边内容。
